Screenings4u Workforce Compliance - Customer Portal Routing Fixes

Updated customer routing to preserve four distinct roles:
- Platform Admin -> /admin/dashboard.html
- Employer Admin -> /employer/dashboard.html
- C/TPA Admin -> /ctpa/dashboard.html
- Owner-Operator Admin -> /owner-operator/dashboard.html

Key fixes:
1. login.js now uses workforce-session-context.portal first, with role/org/audience fallbacks.
2. portal.js now recognizes owner_operator as a distinct customer portal and reads the current session-context subscription shape.
3. navigation.js no longer injects Platform Admin navigation into Employer, C/TPA, or Owner-Operator customer pages. Admin navigation is restricted to /admin/ paths.
4. Owner-Operator pages now identify themselves as Owner-Operator Workspace / Owner-Operator Administrator rather than Employer Workspace / Employer Administrator.
5. Internal links for employer, ctpa, and owner-operator portal HTML pages were validated; no missing local targets were found.
6. Platform Admin role behavior was not changed.
